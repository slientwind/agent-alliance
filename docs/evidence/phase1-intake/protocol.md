# 项目资料录入候选组件验证

从第3节及第7节选择真实格式的合成资料，检查默认命令行本地解析的实际产物。每项记录输出、退出码和可核对的事实。转换成功仅表示命令已返回。

| 输入 | 成功判据 |
| --- | --- |
| 区域明细 CSV / 缺列 CSV | 看到编号001、核准状态及小数原值；缺状态列时只报告输入内实际存在的列。判定能否核准由业务规则处理 |
| Excel工作簿 | 核对四个原编号、两位金额显示、来源工作表及行定位。任何差异分开登记；用于计算时回到原始单元格 |
| 培训讲义 / 两页课件 | 两条规则原文可定位。区分段落/页码/幻灯片号，按转换实际提供的信息验收 |
| 可搜索PDF / 同内容的纯图PDF | 可搜索版本应能找到真实中文；纯图版本未启用OCR时，绝不能当作已取得可引用正文 |
| 空的DOCX占位文件 | 应可识别无法提取可用正文。允许退出错误或输出为空，但平台不得展示已经验收或索引就绪 |
