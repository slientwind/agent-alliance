# 公开 Agent 的接入与协作试运行
使用 A2A 官方样例仓库的 LangGraph Currency Agent 原样运行。公开汇率数据只用于可复核的合成任务。平台用独立临时数据及本机地址；模型使用本机固定的 Qwen3-4B Q4_K_M。仅允许本轮已知的公开查询与本机调用。

1. 取得运行端点的 Agent Card，按原声明登记名称、协议版本和操作。通过平台登记后直接调用“2024-06-03 每1欧元兑换多少美元”。比较工具实际取得的历史数据及独立读取结果，回复应明确日期、方向与数值。
2. 注册受管中文简报助手，以发布版本依次执行公开 Agent 和简报助手。检查外部任务标识、两步输入输出以及中文简报的日期、方向和汇率；需要远端实际结果进入下一步，不能由主持人复制。
3. 对缺目标币种的请求，预期追问或明确阻塞；检查平台是否保留远端真实状态，是否提前启动下游。对超出汇率范围的任务不予采信，不登记通用研究能力。
4. 区分逐步的证据：Card、实际调用、事实正确、可衔接、异常可恢复和可发布。查询、推送、取消与企业账号权限均单列。
