# 培训课件试运行
本次是合成业务验证。任务为根据给定制度将领取、归还、遗失处理做成三页可编辑 PPTX，再采纳新制度，仅更新领取页的跨部门确认要求。源资料采用 fixtures/phase1/training-rule.md 和 T3-v2.md。试验使用上轮同一模型和种子，任务工具只有文本转换和预览。主持人负责调用现有软件，不修订模型内容。
首次验收要求：三页均有准确且独立的标题与操作说明。领取页写清员工填写用途和预计归还日、部门负责人确认后领取；归还页写清由保管员核对设备编号并登记；遗失页写清立即报告保管员。禁止自行增设手续。修改后领取页保留原要求，补充接收部门负责人确认。页二、三的文字与可见版面应保持原样。分别检查幻灯片数、原生可编辑文本、PPTX 重开、导出 PDF、逐页渲染、事实准确性及冻结区域。异常保留原稿和输出，仅变更拟复验的环节。来源修订登记在交付清单，无需改动未受影响页面的文字。

复验分组：先试自由生成；若失败，逐页摘录，再让同模型从人工切分并逐句核对的条款列表选择编号。需要确认文件链路时，主持人另做一份依照原文选条的对照课件，明确标示人工选条。最后用另一份本机开源模型重跑原始同题，提示词、种子和输入保持一致。新模型独立生成结果。保留每一组，分开报告内容和文件的通过情况。

独立样例采用 P2.md 的新品评审资料。两页简报分别说明已知规格和待补资料，核对产品编号 CW-01、容量480 mL、海蓝色、包装含杯和说明卡、缺零售价、缺保温时长测量资料及产品审核人八项，额外捏造的数值或结论判失败。两种本机模型接收同一输入；本题只检验基础演示文稿制作与缺资料的表达。

### 从描述创建草稿
同一业务描述交给本地模型生成草稿。核对 JSON 是否可解析、草稿状态、三项操作是否在目录、是否保留缺资料和定向修改要求。使用生成的 instructions 原样试跑新品资料 P2，两页简报和事实要求与独立样例相同。配置或运行失败保留原结果。主持人中转临时配置，不赋予平台权限，不发布为共享能力。即使单次成功仍要在实际组合中逐操作验证。
