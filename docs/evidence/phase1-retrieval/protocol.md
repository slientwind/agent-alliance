# 中文检索组件实验

先固定8个合成问题、期望首条引用和负例。原句按资料正文中的句号切分，从1开始编号。主资料为培训和新品v2，加入同企业未授权团队、外企业、旧版本及旧索引干扰。初始读者为示例企业A的项目审核人。只准当前获授权资料参与新检索。持有历史引用时单独按当前授权判断能否读取。

试验只测字面检索基线。去空白标点，保留大小写归一的字母数字和汉字，以相邻字符对的出现次数形成向量，在PostgreSQL以pgvector余弦距离做精确排序。最低相似度0.10，最多返回三条，首条同分按引用ID排序。字表由初始语料及查询以确定顺序建立，用作此次固定实验。问题的标准答案不参与计算。原词、口语、无答案分别记实际结果；授权必要项要求每项零泄露。后续增加分词、同义词或百炼向量时另开批次，每次继续保留本批结果。

撤权实验先确认共享前不可读、共享后可读，再撤销培训源访问，保留旧索引和缓存引用以重试搜索与正文获取。灾备实验在授权有效时做业务库逻辑备份，撤销后恢复至另一个数据库，先测隔离库的陈旧授权，之后重放独立保存的撤权事实并重复检查，测量可见行数。全部为合成数据。

第二批在首次语义推理前固定比较条件。沿用原8题，新增4题单独统计。本地采用 BAAI/bge-small-zh-v1.5 的固定 ONNX int8 转换版，问题使用模型卡的中文检索指令，文档按原句输入，取首个 token 的归一化向量。独立向量列以实际输出维度建立。候选按余弦相似度降序，门槛预设0.55，最多3条。保留全部误命中和漏召回。该实验只评估单句引用选择和无答案拒答，模型为离线比较用途。企业默认百炼M04按实际地域、凭据、索引版本单独验收。

第三批为探索性双路排序。沿用首批固定字表和0.10字面门槛，以及次批固定语义模型和0.55门槛。各路取前三条，以各路1/(60+名次)之和排序，同分优先字面名次，再按引用ID。两路都无候选则返回空集。历史两批问题用于回归，额外4题在本轮打分前固定并单独报告。该策略选择是在观察过两种单路结果之后作出。
