# Agent Alliance 对话工作区交互设计

2026 年 11 月 22 日修订。打开[交互原型](uiux/index.html)或[可离线分享的单文件](../artifacts/Alliance-交互设计原型.html)。首页直接输入需求。桌面和手机均从左上角打开历史对话。原型使用本地固定样例和模拟执行。

## 如何完成一件工作

| 用户所处位置 | 页面优先显示 | 用户可以做什么 |
| --- | --- | --- |
| 新对话 | 宽幅多行输入框，左下角放附件与 Agent 入口，右下角发送 | 直接提问或描述交付物。能用现有资料回答的简单问题直接给出答案及依据，用户可明确采纳 |
| 需要澄清 | 一次问一个影响产出的业务问题 | 自由回复或点选建议。同一条对话保留最初诉求与答复 |
| 准备执行 | 简短说明交付物、用途、预计费用、修改方式和最终确认人 | 确认执行，或修改用途与分工。成员无需先认识各个 Agent；需要时才展开资料与负责人 |
| 正在执行或阻塞 | 当前进展、已完成数量、需要谁提供什么 | 离开后从历史继续；补资料、授权或处理异常后恢复。执行结束直接在对话中给出候选成果 |
| 查看、修改和审核 | 当前稿件、版本、来源以及可执行的动作 | 阅读成果，直接说“把标题改成……”。修改前核对受影响成果，修订后审核具体版本 |
| 完成交付 | 两项已审成果与版本清单 | 最终确认人核对并固定版本；随后可以下载。手机可逐项审核，复杂成果包沿用桌面最终核对规则 |

例如输入“帮我准备随行杯新品的内部评审材料”。助手询问用途，用户回复“给品牌组评审”。页面中直接出现方案；确认执行后，产品介绍和素材清单出现在原处。回复“把标题改成海蓝色随行杯”，助手说明正文可沿用、清单引用需要复核。只有版本被明确审核和确认后，才显示已交付。销售分析和培训任务沿用这套交互。

### 从业务需求创建生图助手

成员在输入框写下需求后，进入「Agent → 创建 Agent」，可以继续编辑这段描述。如果相同成果类型下已有名称相近或职责相同的已发布 Agent，折叠项列出匹配理由、职责、修订和费用承担方。可直接使用，或将其追加到正在编排的步骤。主动选用前仍可继续独立创建。选择图片成果后，仅列出有权使用的生图模型。存在一个适用的团队模型时预选其修订；有多个可选时由用户指定。创建前显示费用承担方和草稿共享范围。用户填写样图要求和视觉验收标准，验收人默认本人，可改为同团队的另一位成员。保存样例和授权生成图片是两个独立操作。

创建者或指定验收人可以稍后从「我的生图草稿与验收」回到相同修订。验收人打开样图、给出结论与依据，管理员才能发布通过验证的版本。回到输入框仍能继续原需求。若团队访问权变化，界面收起样图和相关操作，服务端重新核验对原件的读取和审核权限。[手机样图](evidence/rebuild-image-agent-entry/image-agent-sample-mobile.png)

### 在对话里寻找已有能力

搜索结果展示匹配业务词、已发布修订、实际产出及费用承担方。成员输入完整任务描述后可直接选择，也可先核对同类 Agent 的说明。从空白对话开始组合时，后续步骤的名称查询不会覆盖第一步的任务描述。单独搜索 Word、Excel 或 PNG 等格式时只显示能产出该格式的能力。在现有任务中单独搜索一个能力再新建，使用搜索描述填写 Agent 职责。仅输入格式时预选对应产出，用当前对话说明任务。在同一面板返回列表后，「继续未提交的配置」保留名称、模型修订和工具列配置，「创建 Agent」按当前需求重新填写。输入关键词的过程在当前可见的目录内完成；创建、验证和调用都有独立入口。[手机搜索](evidence/rebuild-agent-discovery/agent-picker-mobile.png) · [创建时的复用选择](evidence/rebuild-agent-discovery/agent-description-reuse.png)

### 在对话里补齐文件制作能力

例如成员上传收款明细，希望交付一份按区域汇总的 Excel。可以直接选用现有汇总 Agent，也可从「创建 Agent」选择「Excel 分组汇总」。点「从附件读取列名」后选定分组列和金额列，需要时再展开单位与筛选条件。如果只有一个可用团队，界面直接说明费用和草稿归属。成员另填一份允许共享的试算样例，打开生成的工作簿核对金额。关闭后，从「我的制作草稿与验收」可以继续。

如果是规划助手发现缺少能力，成员可以在原方案选择「用内置工具补齐能力」。试运行原件随这项缺口展示。管理员发布后，成员采用该修订，返回原业务目标和已选资料，核对方案后启动运行。[手机端汇总字段选择](evidence/rebuild-quick-tools/quick-tools-columns.png)

在规划授权区，指定交付文件格式收在折叠项中。直接描述成果即可发起规划。例如，附件为盘点明细，目标是逐行交付 Excel，可以在建议中看到工作簿格式、缺失操作和可复用修订。若输入是 Word 议程，目标只是回答签到时间，则按文本答复核对。使用者在同一任务中试做、审核及采用，不需要进入组织设置。

### 从输入框组合助手

在 Agent 选择框中打开「组合 Agent」，按任务顺序添加已发布修订。每一步展示版本和承担费用的团队，可提前或移除。单一团队时直接展示项目归属，组合涉及多个团队时可单独选择归属。点「使用此组合」返回原输入框，保留需求和附件，组合摘要可再次展开调整。发送后以相邻步骤接力作为初始依赖，后一步读取前一步的文本结果。图片与文档原件在成果审核中预览。项目的方案编辑器支持进一步分支与合并。确认界面列明本次授权的调用范围。

### 编辑方案时切换项目

在正式工作区，编辑交付目标、步骤依赖、资料或个人偏好后，页面显示草稿基于哪个项目修订。切换到另一个项目再回来，可继续编辑原稿。两个窗口同时修改时，后提交的一方能看到当前已保存的目标、分工和引用，选择沿用自己的草稿或放弃修改；沿用后仍需主动保存。刷新页面会清除本页草稿。

确认执行时，用户看到已保存方案的交付目标、最终确认人，以及每一步成果可用的修改方式。运行开始后，尚未提交的方案草稿可查阅和丢弃。新版本须重新勾选本次调用授权。

### 填写预算申请时切换项目

项目费用摘要显示「有预算申请草稿」。重新打开申请时，页面恢复原预算对象、阻塞任务、金额或次数、不足原因、剩余工作和替代方案。草稿只保留在当前页面，刷新、登出或检测到成员失去项目访问权后清除。项目已结束时可查阅、丢弃原稿。

平台按当前可申请范围与原修订核对。额度或任务修订变化时，申请人核对后才能提交。原对象已不可用时，申请人须重选预算范围或任务，也可明确改选「仅申请额度」。更换预算对象后需重新填写金额或次数。

仅在获得明确回执后清除对应草稿。回执中断时，可查看申请记录，再以原申请标识重试。旧版本已经受理时会提示核对记录。要另行申请可丢弃这份草稿后重新填写。

### 修订成果时切换项目

每份成果有独立的修订表单。文本保留修订正文和原因，Office 文件保留本页选定的文件、摘要和原因。遇到并发新版，表单展示当前正文或文件摘要，并保留自己的修改供核对。核对后可继续编辑文本，或下载当前原件、重新选择修订文件。离开审核阶段后草稿可查阅或丢弃；项目审核权限收回后清除该项目的本页修订草稿。

## 空间与图标

首屏将可编辑的多行输入区铺开。首条消息发出后，消息流占据主体空间，可以独立滚动，续写框固定在底部。浏览器实测，1440 × 900 桌面首屏编辑框占视口面积 68.6%，对话中的消息流占 72.9%；390 × 844 手机首屏编辑框占 68.7%。面积以对应元素外框除以视口面积计算。

输入框只显示当前需要的操作。「＋」收纳资料和示例，「↑」发送，空白时禁用。历史、新建和账号入口位于顶栏。图标使用同一套线性图形、44 像素操作区和可读名称，桌面悬停可查看名称。模板、模型与管理指标均在二级入口。

### 配色与字重

桌面与手机统一采用浅色黑白界面。交互原型在窄屏顶栏中省略过长的对话标题，为历史、账号和新建按钮保留完整点击区域。顶栏、输入框和成果卡片用白色，页面背景采用浅冷灰（#F3F4F5），书写区用细灰线划界。正文用墨黑色（#101112），辅助说明用冷深灰（#595A5B）。品牌名用中等字重，「新对话」用粗体标题；附件图标用次级灰，输入后可发送的箭头用黑底白色。确认按钮同样使用黑底白字。历史侧栏以冷灰底、左侧黑线和粗体标识当前对话，状态说明保持常规字重。「最近对话」和「我的待办」两个切换按钮以黑色底线和粗体标识选中项。交付物名称、当前版本、待处理状态和主要动作加粗，管理大盘对需要处理的非零数值加粗，包括执行阻塞、执行失败和待核对回执。常规计数使用中等字重。消息正文使用常规字重（400），三级小标题使用半粗体（600），主要操作使用粗体（700）。费用明细和次级折叠项默认用常规字重，展开项的标题用半粗体标出阅读位置。登录结果用冷灰底提示，正文保持清晰可读。键盘聚焦输入框时显示连续的深色描边，原始成果预览保留文件自身的颜色。审核状态同时提供明确文字；待审核采用实心菱形，已审核采用空心圆。

正式工作区用合成数据在 Chromium 中走查。桌面 1440 × 900 和手机 390 × 844 上，首屏对话输入区各占视口面积约 69%，其中可编辑文字区域占视口高度约 61%。[桌面对话](evidence/rebuild-monochrome/desktop.png) · [手机对话](evidence/rebuild-monochrome/mobile.png) · [管理大盘](evidence/rebuild-monochrome/monitor.png) · [颜色与布局核对](evidence/rebuild-monochrome/visual-check.json)

带两份附件的新对话也在 320、390 和 1440 像素宽度走查。附件在输入区底部逐份显示，单一归属的普通成员可直接发送。三种宽度下输入框约占首屏面积的 68% 至 69%，附件、Agent 和发送入口均在视口内。[桌面实屏](evidence/rebuild-multi-csv/composer-1440.png) · [手机实屏](evidence/rebuild-multi-csv/composer-390.png)

## 导航与权限

- 历史导航默认收起，顶部按钮展开侧抽屉。抽屉中可新建、搜索或继续最近对话，每条历史都展示工作标题与状态。会话中也可从右上角直接新建。
- 「我的待办」按成果审核、预算追加和能力授权筛选。选择「成果审核」后按当前身份展示可审核的成果、分配的反馈和最终交付确认。每条标出项目、步骤和成果版本，可直接定位原文。成员打开旧待办时先读取最新项目；如果同事已处理或转交，页面显示当前状态。
- 「预算追加」按当前预算负责人归集多个承担团队的金额和调用次数申请。预算负责人可查看申请时与当前额度、追加后的额度和申请理由，直接批准或拒绝。项目成员可见标题并进入项目，其他负责审批的成员按项目编号辨认申请。打开旧入口会读取最新结论；预算负责人转交后由接任者处理。
- 输入框旁的「Agent」优先显示搜索框和「创建 Agent」，同一页提供组合和模板。试运行前显示费用承担方与估价状态。能力库、服务与渠道可从「我的工作区」进入，授权事项收在「协作与授权」，登录身份和飞书绑定收在「账号设置」。当前任务缺少能力时，直接在方案内进入绑定与试运行，随后返回该对话。
- 资料、决策记录、费用和运行详情收在当前对话的「对话详情」。通知与阻塞消息链接到相关任务；消息中的审批按钮须核对当前权限和版本。
- 管理员与普通成员共享首页。「企业管理」默认打开「模型与 Agent」，用户资料和用量从「用户与监控」互查，团队、部门及范围授权位于「高级设置」。默认原型使用普通用户视图，通过页面查询参数 role=admin 可评审管理员入口。正式鉴权及统计口径见[产品第25节](10-product-blueprint.md#enterprise-instance-admin)。

### 企业管理中的运行监控

默认查看近 30 天的企业汇总。选择近 7、30 或 90 天，再选发起成员或应用，数量与费用一起更新。执行完成、能力样例检查通过、成果版本审核通过、简单回答已采纳、正式交付批次分别显示。有阻塞或未核实费用时，相应数字加粗。展开「统计口径」可查每项归给谁、按哪个时间计算。窗口读取失败时显示当前周期的错误；切换范围可重新读取。

运行监控和获授权的范围汇总均可展开「运行状态分布」。折叠时显示执行中和失败数，有失败时加粗数量。暂停、等待回执、普通阻塞各占一项。收到远端明确的失败或拒绝回执后，用户从当前运行的控制表单填写原因，确认是否结束。其他分支仍有待核对的调用时，平台保留核对入口。

从成员资料进入用量，大盘保留日期和团队筛选，再按成员显示运行与费用。单团队实例直接显示企业范围，可按成员或应用筛选。返回资料后可展开账号变更记录。当前成员行以冷灰底、黑色左边线和加粗姓名标识，历史记录和常规计数保持常规或中等字重。变更表单加粗将生效的角色和登录状态，列出需交接的项目及待审版本数量。成员在自己的工作区查看未读账号通知，逐条标记已读。

管理员从「管理汇总授权」明确选择企业全域、团队或部门，并决定是否开放该范围的用量与费用。成员从自己的工作区打开「获授权的管理汇总」。先前所选范围撤销或到期后，旧数据收起；有其他范围时，由成员明确选择要查看的范围。管理员可核对最近 50 条已结束授权的原授权人、原因和结束时间。

在获准的团队或部门汇总内，成员可展开「成员与任务明细」，按发起人名称筛选或直接进入全部任务。任务以编号标识，突出当前状态、阻塞类别及最终确认人。逐任务费用在获准时显示。打开明细后固定统计周期，翻页保留所选发起人；管理身份和汇总导出均不授予明细访问权。

选中企业全域时表单说明覆盖所有团队、部门和无部门记录的历史活动。管理员自己持有全域导出权时，可在运行监控的全部发起人视图准备导出；切换到个人或应用后，收起全域导出表单。

导出权可以单独授予或收回。成员打开导出表单后先核对组织范围和起止时间，再填写接收方与用途；有费用查看权时可主动勾选费用。生成后由申请人下载 JSON 文件。收回导出权后，该成员仍能在页面查看获准的汇总，已签发的下载立即失效。再次开放导出时需要重新生成文件。

在持有财务导出权的范围内，「准备导出逐笔费用」会打开包含范围、起止时间和文件字段的表单。可以按本地时间缩短周期，再填写用途与接收对象。财务文件单独列在「查看近期费用文件」中。管理员切换到单个发起人时，收起企业全域财务导出入口。

## 原型验证范围

[桌面首页](uiux/previews/desktop.png)、[手机首页](uiux/previews/mobile.png)、[对话中的方案](uiux/previews/plan.png)及[版本审核](uiux/previews/review.png)由浏览器走查生成。桌面覆盖自由输入、追问、调整用途、模拟执行、用文字指定新标题、关联复核、逐项审核、确认、下载及刷新后恢复。另覆盖简单摘要采纳、缺资料恢复和角色入口。手机单文件覆盖发起到逐项审核、切换对话、320 像素窄屏及多成果包转桌面确认提示。

可演示的资料包括随行杯、核准销售记录和设备借用制度。原型遇到其他需求会请用户选择样例。附件仅记录文件名，文字修改演示主标题及清单引用。任意自然语言理解、真实文件读取、模型执行、企业权限与多人协同仍需在运行系统中另行验证。


### 对话内的跨团队授权

「跨团队能力授权」默认折叠。展开后，白底列表把承担团队、资源、操作、单次估价、已用次数和有效期逐行对齐。待资源授权、待预算确认或次数用完时，使用实心菱形和粗体文字。已批准和已关闭的状态采用空心圆及常规灰字。提供方从「我的待办 → 能力授权」按当前职责处理资源或费用决定，回到对话即可继续原方案。[桌面实屏](evidence/rebuild-project-agent-grants/project-agent-grant.png) · [手机实屏](evidence/rebuild-project-agent-grants/project-agent-grant-mobile.png)


### 选择项目团队和能力归属

新对话的大输入区提供消息、资料和 Agent。只有一个可用团队或有有效默认团队时直接采用。已加入多个团队的成员可从「我的工作区 → 协作与授权」打开「更改项目归属」。无默认且有多个可用归属时，首次发送展开并聚焦归属选择，保留需求与附件，选择后再次发送才创建项目。有多个可用团队且当前采用非企业默认归属时，输入区显示归属名称，点名称即可改选。同一页面提交普通任务后，有有效默认时下一次回到默认归属，无默认时沿用已选归属。刷新后重新判断。临时选用 Agent 时，按本次选择确定项目归属及费用，移除或用完该选择后恢复普通对话归属。退出原团队后保留草稿，重新选择有效归属后才能发送。

候选列表按已写需求与发布版名称及职责的匹配排序，显示匹配词，保留其他可选能力。用户点选后才带入草稿。

从输入框选择已发布 Agent，或从能力库点击「使用…开始对话」，均带回具体发布修订、费用承担方和原来的需求。能力库仅在新对话尚未选择 Agent 时提供此快捷操作。所有可见能力均属于唯一已加入团队时，归属在列表顶部统一显示。

输入区在用户写出可匹配的任务描述后显示至多两个 Agent 按钮，用粗体标出名称并列出命中的任务词。多团队时显示候选归属。推荐和点选都沿用现有输入区，不打开额外页面。内置模板从 Agent 列表打开，成员可在可用的发布版本下点「用于当前对话」，回到原需求和附件。

能力库登记工具和外部 Agent 的表单分别提供「归属及费用承担团队」。外部能力的授权卡还展示原任务的查询、取消范围、每轮核对时限和失败重试次数，预算负责人可在确认承担费用前阅读。[外部能力审批实屏](evidence/rebuild-borrowed-connectors/borrowed-finance.png)


### 从对话选用编稿与排版能力

单一团队的首次配置页直接写明费用承担方。课件任务在对话输入区提供「编写分页提纲」，同团队有已发布文本能力时另提供「让 Agent 编稿」。后者展示候选的实际名称、版本及能力说明，选择后在输入区显示两步顺序，可调整组合并附加原件。执行前仍需确认方案与用量。手机审核可打开 PDF 预览，反馈面板支持按页填写标题和正文；旧版预览与已审核的可编辑原件分别保留。[手机选用编稿 Agent](evidence/rebuild-course-deck/course-writer-picker.png) · [审核中的手机预览](evidence/rebuild-course-deck/course-review-mobile.png)
